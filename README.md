# traces
Module de gestion de traces applicatives


# trace-contract
Jar contenant le contrat d'interface pour communiquer avec le microservice de publication de traces

# trace-consumer
Microservice de consommation de traces applicatives (consommation depuis RabbitMQ)

# trace-publisher
Microservice de publication de traces applicatives (permet de valider les dépôts via contrat)
Rejouabilité des anomalies par scheduler (cron)
